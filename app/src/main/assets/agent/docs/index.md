StarLight를 설치하고, 첫 봇을 만들고, 프로젝트와 플러그인을 관리하는 방법이에요. **StarLight를 처음 쓴다면 여기서 시작하세요.**

- [설치와 초기 설정](/docs/app/start/install) → [첫 봇 만들기](/docs/app/start/first-bot)
- [이벤트 함수](/docs/app/reference/events)와 [스크립트 API](/docs/app/reference/script-api)
- [문제 해결](/docs/app/guides/troubleshooting) — 봇이 반응하지 않을 때

## NeonJS

StarLight의 새 자바스크립트 언어예요. ES2025 문법, 모듈, `fetch`, Java 연동으로 스크립트를 작성해요.

- [NeonJS](/docs/neonjs) — Rhino와의 차이와 고르는 기준
- [첫 NeonJS 스크립트](/docs/neonjs/start/first-script)
- [모듈 나누기](/docs/neonjs/guides/modules), [Java와 Android API 쓰기](/docs/neonjs/guides/java), [비동기와 네트워크](/docs/neonjs/guides/async)
- [Rhino 프로젝트 옮기기](/docs/neonjs/guides/migrate-from-rhino)

## 플러그인 개발

Kotlin으로 StarLight에 새 API, 이벤트, 설정 화면, 홈 위젯을 더하는 플러그인을 만들어요.

- [플러그인 개발 문서](/docs/plugins) — 플러그인의 구성과 읽는 순서
- [개발 환경 준비](/docs/plugins/start/setup) → [첫 플러그인 만들기](/docs/plugins/start/first-plugin)
- [SDK와 변경 사항](/docs/plugins/sdk)

> [!NOTE]
> 문서는 **스냅샷 채널(StarLight 1.0.0 개발 빌드, nightly 브랜치)** 을 기준으로 해요. 베타(0.3.4b)와 정식 채널의 앱에는 NeonJS가 없고, 일부 화면과 기능이 다를 수 있어요.
