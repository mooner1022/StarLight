**홈** 탭은 위젯을 놓는 격자예요. 처음에는 **봇 상태**와 **로그** 위젯이 놓여 있어요. 위쪽에 **⚠ 전원: 꺼짐**이 보이면 설정의 **전역 전원**이 꺼져 있다는 뜻이에요.

## 위젯 편집

1. 위젯을 길게 누르거나, 격자 아래의 **위젯을 길게 눌러 편집**을 눌러요.
2. 편집 모드에서는 위젯을 끌어서 옮기고, 테두리를 당겨 크기를 바꿔요.
3. 위쪽 막대의 버튼으로 위젯을 다뤄요.
   - **위젯 추가** — 추가할 위젯을 골라요. StarLight 기본 위젯은 **StarLight** 아래에, 플러그인 위젯은 플러그인 이름 아래에 있어요.
   - **위젯 설정** — 고른 위젯의 설정을 바꿔요. 설정이 있는 위젯에만 보여요.
   - **위젯 제거** — 고른 위젯을 지워요.
4. **완료**를 누르거나 빈 곳을 누르면 편집이 끝나고 배치가 저장돼요.

## 기본 위젯

| 위젯 | 보여 주는 것 | 설정 |
|---|---|---|
| **봇 상태** | 전원, 알림 접근, 패키지 규칙, 프로젝트 상태를 점검해요. 문제가 있는 줄을 누르면 고치는 화면으로 가요. | — |
| **업타임** | 앱이 켜진 뒤 지난 시간이에요. | — |
| **로그** | 최근 로그예요. **더보기**로 더 볼 수 있어요. | **최소 로그 수준** |
| **오류 모니터** | 최근 오류를 모아 보여 줘요. | **목록에 경고도 표시** |
| **실행 중 작업** | 프로젝트별로 실행 중인 작업이에요. | **작업 중인 프로젝트만 표시** |
| **메시지 활동량** | 받은 메시지의 양이에요. | — |
| **스크립트 값** | 스크립트가 `HomeWidget` API로 내보낸 값이에요. | **표시할 프로젝트** |

> [!NOTE]
> 새로 설치한 직후에는 **봇 상태** 위젯의 패키지 규칙 항목이 **규칙 없음**으로 보일 수 있어요. 기본값인 **규칙 자동 설정**이 켜져 있다면 카카오톡 메시지는 정상적으로 받아요.

## 스크립트 값 위젯

스크립트에서 `HomeWidget`으로 값을 내보내면 **스크립트 값** 위젯에 한 줄씩 보여요. 봇의 처리 횟수나 마지막 실행 시각처럼 자주 확인할 값을 띄워 두기에 좋아요.

```javascript title="main.js"
let count = 0;

export function onMessage(event) {
    count++;
    HomeWidget.set("count", "받은 메시지", count);
}
```

| 메서드 | 설명 |
|---|---|
| `HomeWidget.set(key, value)` | `key` 줄에 값을 보여 줘요. |
| `HomeWidget.set(key, label, value)` | 이름표(`label`)와 함께 보여 줘요. |
| `HomeWidget.remove(key)` | 그 줄을 지워요. |
| `HomeWidget.clear()` | 이 프로젝트의 줄을 모두 지워요. |
