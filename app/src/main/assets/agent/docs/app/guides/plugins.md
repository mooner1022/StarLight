플러그인은 StarLight에 새 기능을 더하는 확장 파일(`.slp`)이에요. 스크립트에서 쓸 API, 새 이벤트, 새 스크립트 언어, 홈 위젯, 다른 메신저 연동 등을 더할 수 있어요.

**플러그인** 탭에는 설치한 플러그인이 **메신저 연동**, **스크립트 엔진**, **라이브러리**, **유틸리티**, **개발 도구**, **기타**로 나뉘어 보여요.

> [!IMPORTANT]
> 플러그인을 설치, 업데이트, 제거하거나 켜고 끄면 **앱을 다시 시작해야** 적용돼요. 바뀐 내용이 있으면 목록 위에 **재시작** 버튼이 나와요.

## 설치하기

### 파일로 설치

1. **플러그인** 탭의 **설치**를 눌러요.
2. 파일 선택 화면에서 `.slp` 파일을 골라요.
3. **플러그인 설치** 시트에서 이름, 버전, 개발자, 설명을 확인해요. 이미 설치된 플러그인이면 업데이트인지, 같은 버전인지, 낮은 버전인지 알려 줘요. 앱 버전과 맞지 않거나 필요한 플러그인이 없으면 경고가 함께 나와요.
4. **설치**를 누르고 앱을 다시 시작해요.

파일을 직접 `StarLight/plugins/` 폴더에 복사해도 돼요. 앱을 다시 시작하면 불러와요.

### 저장소에서 찾기

툴바의 **스토어** 버튼을 누르면 **플러그인 저장소**가 열려요. 공개된 플러그인을 둘러볼 수 있어요.

> [!CAUTION]
> 플러그인은 앱과 같은 권한으로 실행돼요. 믿을 수 있는 곳에서 받은 플러그인만 설치하세요.

## 플러그인 카드

카드에는 버전, 개발자, 파일 크기가 보이고, 문제가 있으면 **로드 실패**나 **앱 업데이트 필요** 같은 상태가 대신 보여요.

카드를 눌러 펼치면 켜고 끄는 스위치와 버튼이 나와요.

| 버튼 | 하는 일 |
|---|---|
| **설정** | 플러그인의 설정 화면을 열어요. 설정이 있는 플러그인에만 보여요. |
| **초기 설정** | 플러그인이 처음 쓸 때 필요한 값을 다시 입력해요. 요청한 플러그인에만 보여요. |
| **정보** | 버전, 상태, 개발자, 설명, 메인 클래스, 출처, 데이터 폴더를 보여 줘요. |
| **제거** | 플러그인 파일을 지워요. **설정과 데이터도 삭제**를 고르면 플러그인 데이터 폴더도 함께 지워요. |

다른 플러그인이 의존하는 플러그인을 끄려고 하면 한 번 더 확인해요.

## 초기 설정

API 키처럼 처음에 값이 꼭 필요한 플러그인은 **초기 설정**을 요청해요. 앱이 시작될 때 설정 창이 뜨고, 카드에는 **설정 필요**가 보여요.

- 값을 채우고 **완료**를 누르면 플러그인이 값을 확인해요. 잘못된 값이면 다시 입력하라고 알려 줘요.
- **나중에**를 누르면 다음부터 시작할 때 묻지 않아요. 카드의 **초기 설정** 버튼으로 언제든 다시 열 수 있어요.

## 안전 모드

플러그인 때문에 앱이 제대로 실행되지 않으면 **설정 → 프로젝트, 플러그인**에서 **안전 모드**를 켜요. 플러그인을 하나도 불러오지 않고 앱을 실행해서, 문제가 있는 플러그인을 지울 수 있어요. 다 고쳤다면 플러그인 탭의 **끄고 재시작**으로 안전 모드를 끄세요.

## 플러그인 파일 위치

| 경로 | 내용 |
|---|---|
| `StarLight/plugins/<ID>.slp` | 플러그인 파일 |
| `StarLight/plugins/<이름>(<ID>)/` | 플러그인 데이터 폴더. 설정은 `config-plugin.json`에 저장돼요. |

플러그인을 직접 만들고 싶다면 [플러그인 개발 문서](/docs/plugins)를 보세요.
