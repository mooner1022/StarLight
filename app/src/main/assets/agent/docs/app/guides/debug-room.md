디버그 룸은 **한 프로젝트에만** 메시지를 보내 보는 채팅 화면이에요. 카카오톡이나 다른 사람 없이 봇의 반응을 바로 확인할 수 있어요.

## 여는 방법

- 프로젝트 카드를 펼친 뒤 **디버그**
- 에디터 툴바의 **디버그 룸**

프로젝트가 **컴파일된 상태**여야 열 수 있어요. 프로젝트를 켜 두지 않아도 돼요.

## 메시지 보내기

아래 입력창에 메시지를 쓰고 보내면, 이 프로젝트의 `onMessage` 함수가 불려요. 설정에서 **레거시 이벤트 사용**을 켰다면 `response` 함수도 함께 불려요.

- 봇의 답장은 봇 이름(기본 `BOT`)의 말풍선으로 보여요. 500자가 넘는 답장은 긴 말풍선으로 보여요.
- `<@이름>`이라고 쓰면 `@이름` 멘션으로 바뀌어 전달돼요.
- 스크립트가 읽음 처리를 부르면 **읽음 처리 호출됨** 안내가 떠요.
- 스크립트에서 오류가 나면 프로젝트 이름과 함께 **자세히 보기** 버튼이 나와요.

대화 기록은 프로젝트마다 `debugroom/chats.json`에 저장돼요.

## 디버그 룸 설정

아래쪽 시트를 끌어 올리면 설정이 나와요. 이 설정은 모든 프로젝트의 디버그 룸에 함께 적용돼요.

| 분류 | 항목 |
|---|---|
| **일반** | **방 이름**, **앱 패키지**(기본 `com.kakao.talk`), **isGroupChat**(단체방인지), **엔터 키로 전송** |
| **봇** | **이름**, **프로필 이미지 설정**, **채팅 말풍선 색 설정** |
| **전송자** | **이름**(기본 `debug_sender`), **프로필 이미지 설정**, **채팅 말풍선 색 설정** |
| **위험** | **대화 기록 초기화** |

## 실제 메시지와 다른 점

디버그 룸에서 온 이벤트는 실제 카카오톡 메시지와 조금 달라요. 스크립트에서 구분하려면 `event.room.isDebugRoom()`을 확인하세요.

| 값 | 디버그 룸에서 |
|---|---|
| `event.room.isDebugRoom()` | `true` |
| `event.sender.id` | `null` |
| `event.chatLogId` | `-1` |
| `event.image` | `null` |
| `replier.reply(방, 메시지)` | 방 이름을 무시하고 디버그 룸에 보내요. |
