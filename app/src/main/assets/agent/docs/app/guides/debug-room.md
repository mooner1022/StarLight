디버그 룸은 **한 프로젝트에만** 메시지를 보내 보는 채팅 화면이에요. 카카오톡이나 다른 사람 없이 봇의 반응을 바로 확인할 수 있어요.

## 여는 방법

- 프로젝트 카드를 펼친 뒤 **디버그**
- 에디터 툴바의 **디버그 룸**

프로젝트가 **컴파일된 상태**여야 열 수 있어요. 프로젝트를 켜 두지 않아도 돼요.

## 메시지 보내기

아래 입력창에 메시지를 쓰고 보내면, 이 프로젝트의 `onMessage` 함수가 불려요. 프로젝트의 API 방식에 **메신저봇 API2**가 있으면 `bot.on(Event.MESSAGE)`와 명령어 리스너도, **메신저봇 레거시**가 있으면 `response` 함수도 함께 불려요.

- 봇의 답장은 봇 이름(기본 `BOT`)의 말풍선으로 보여요. 500자가 넘는 메시지는 앞부분만 보이고, **전체 보기**를 누르면 모두 볼 수 있어요.
- 카카오톡처럼 보낸 시간과 날짜가 보이고, 같은 사람이 같은 분에 보낸 메시지는 묶여 보여요. 글자 크기도 카카오톡의 기본 크기와 같아요.
- 말풍선을 길게 누르면 메시지가 복사돼요. 긴 메시지는 전체 내용이 복사돼요.
- 봇이 [`MediaSharer.send()`나 `event.room.sendMedia()`](/docs/app/reference/script-api#파일-보내기-mediasharer-room.sendmedia)로 보낸 파일도 채팅에 보여요. 이미지는 사진으로, 다른 파일은 이름과 크기로 보이고, 누르면 이미지·Markdown·텍스트는 앱 안에서 미리 보고 다른 파일은 다른 앱으로 열어요.
- `<@이름>`이라고 쓰면 `@이름` 멘션으로 바뀌어 전달돼요.
- 스크립트가 읽음 처리를 부르면 **읽음 처리 호출됨** 안내가 떠요.
- 스크립트에서 오류가 나면 프로젝트 이름과 함께 **자세히 보기** 버튼이 나와요.

대화 기록은 프로젝트마다 `debugroom/chats.json`에 저장돼요. 봇이 보낸 파일의 사본은 `debugroom/chats/media/`에 두고, 대화 기록을 지우면 함께 지워요.

## 디버그 룸 설정

위쪽의 설정 버튼을 누르거나 아래쪽 시트를 끌어 올리면 설정이 나와요. 이 설정은 모든 프로젝트의 디버그 룸에 함께 적용돼요.

| 분류 | 항목 |
|---|---|
| **일반** | **방 이름**, **앱 패키지**(기본 `com.kakao.talk`), **isGroupChat**(단체방인지), **엔터 키로 전송** |
| **봇** | **이름**, **프로필 이미지 설정**, **채팅 말풍선 색 설정** |
| **전송자** | **이름**(기본 `debug_sender`), **프로필 이미지 설정**, **채팅 말풍선 색 설정** |
| **위험** | **대화 기록 초기화** |

**채팅 말풍선 색 설정**에서는 팔레트에서 고르거나, **직접 고르기**에서 색상환·밝기·불투명도·색 코드로 색을 정해요. 글자색은 고른 색에서 잘 읽히도록 바뀌어요. 팔레트의 첫 번째 색(기본색)을 고르면 라이트·다크 모드에 맞는 색으로 돌아가요.

## 실제 메시지와 다른 점

디버그 룸에서 온 이벤트는 실제 카카오톡 메시지와 조금 달라요. 스크립트에서 구분하려면 `event.room.isDebugRoom()`을 확인하세요.

| 값 | 디버그 룸에서 |
|---|---|
| `event.room.isDebugRoom()` | `true` |
| `event.sender.id` | `null` |
| `event.chatLogId` | `-1` |
| `event.image` | `null` |
| `replier.reply(방, 메시지)` | 방 이름을 무시하고 디버그 룸에 보내요. |
