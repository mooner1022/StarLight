**설정** 탭의 항목을 누르면 세부 화면이 열려요. 설정은 `StarLight/config-general.json`에 저장돼요.

## 일반

| 항목 | 설명 |
|---|---|
| **전역 전원** | 모든 프로젝트의 답장과 처리를 켜고 꺼요. 끄면 어떤 프로젝트도 이벤트를 받지 않아요. 기본은 켜짐이에요. |
| **알림 접근 권한** | 허용 상태를 보여 주고, 누르면 시스템 설정으로 가요. |
| **배터리 최적화 예외** | 예외 설정 상태를 보여 주고, 누르면 설정할 수 있어요. |
| **앱 재시작** | 모든 프로세스를 안전하게 종료하고 다시 시작해요. |

## 프로젝트, 플러그인

| 항목 | 설명 |
|---|---|
| **컴파일 애니메이션** | 컴파일이 끝난 뒤 진행 표시줄이 끝까지 차오르는 것을 잠시 보여 줘요. |
| **전역 모듈 로드** | `StarLight/modules` 폴더를 모듈 경로에 넣어서, 여러 프로젝트가 같은 모듈을 쓸 수 있게 해요. 기본은 꺼짐이에요. [모듈 나누기](/docs/neonjs/guides/modules#여러-프로젝트가-함께-쓰는-모듈)를 보세요. |
| **안전 모드** | 플러그인을 불러오지 않고 앱을 실행해요. [플러그인 설치와 관리](/docs/app/guides/plugins#안전-모드)를 보세요. |

## 알림, 이벤트

| 항목 | 설명 |
|---|---|
| **수신 메세지 로그 표시** | 받은 메시지를 로그에 남겨요. |
| **패키지 규칙 설정** | 어떤 앱의 알림을 메시지로 읽을지 정해요. 아래에서 설명해요. |
| **onNotificationPosted 이벤트 사용** | 모든 앱의 알림을 `onNotificationPosted` 함수로 전달해요. 부하가 늘 수 있어요. |
| **문제 해결 도우미** | 권한, 카카오톡 버전, 패키지 규칙을 점검해 문제를 알려 줘요. |

### 패키지 규칙

기본값인 **규칙 자동 설정**이 켜져 있으면 카카오톡(`com.kakao.talk`)을 기기 기본 사용자 기준으로 읽어요. 대부분은 바꿀 필요가 없어요.

카카오톡을 **듀얼 메신저**나 **업무 프로필**에서 쓴다면 자동 설정을 끄고 **규칙 목록**에 직접 추가해요.

| 항목 | 값 |
|---|---|
| **패키지명** | `com.kakao.talk` |
| **메세지 변환/분석 스펙** | Android 11 이상은 `android_r`, 그보다 낮으면 `default` |
| **유저 ID** | `0` 기본 사용자, `10` 업무 프로필, `11` 업무 프로필(샤오미), `95` 듀얼 메신저(삼성) |

아래쪽 저장 버튼을 눌러 저장해요. 규칙이 맞는지는 **문제 해결 도우미**로 확인할 수 있어요.

## 로그

**로그 파일 보관 기간**, **로그 탭 표시 개수**, **로그 파일 정리**가 있어요. [로그](/docs/app/guides/logs#로그-파일)를 보세요.

## 정보

| 항목 | 설명 |
|---|---|
| **업데이트 확인** | 새 버전을 확인해요. **업데이트 자동 확인**과 **업데이트 확인 채널**(STABLE, BETA, SNAPSHOT)을 정할 수 있어요. GitHub 판에만 있어요. Google Play 판은 Google Play에서 업데이트해요. |
| **앱 정보** | 앱 버전, PluginCore 버전, GitHub, 오픈소스 라이선스를 보여 줘요. |
| **개발자 돕기** | 개발자를 후원하는 방법이에요. |

> [!NOTE]
> 앱의 테마와 언어는 기기 설정(다크 모드, 시스템 언어)을 따라요. 에디터의 색 테마는 [에디터 설정](/docs/app/guides/editor#에디터-설정)에서 따로 바꿔요.

## 개발자 모드

**앱 정보**에서 개발자 이름을 여러 번 누르면 **개발자 모드**가 열려요. 내부 로그 표시, 프로젝트의 **동시 실행 수** 변경 같은 실험적 기능이 들어 있어요. 무엇을 하는지 아는 항목만 바꾸세요.
