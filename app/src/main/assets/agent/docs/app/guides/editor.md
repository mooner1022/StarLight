프로젝트 카드의 **수정**을 누르면 코드 에디터가 열려요. 위쪽에 프로젝트 이름이 보이고, 파일은 탭으로 열려요.

## 툴바

| 버튼 | 하는 일 |
|---|---|
| **컴파일** | 열린 파일을 모두 저장한 뒤 프로젝트를 컴파일해요. 실패하면 **자세히**로 오류를 봐요. |
| **저장** | 바뀐 파일을 모두 저장해요. |
| **찾기** | 지금 파일에서 글자를 찾아요. |
| **디버그 룸** | [디버그 룸](/docs/app/guides/debug-room)을 열어요. 태블릿에서는 오른쪽 서랍으로 열려요. |
| 더보기(⋮) | **바꾸기**, **줄로 이동**, **Beautify(코드 정리)** |

## 파일 서랍

왼쪽 위 ☰ 버튼을 누르면 서랍이 열려요. 서랍에는 탭이 세 개 있어요.

| 탭 | 내용 |
|---|---|
| **파일** | 프로젝트 폴더의 파일 목록이에요. **새 파일**, **새 폴더**, **모두 접기** 버튼이 있어요. |
| **로그** | 이 프로젝트의 로그예요. **로그 지우기**로 비울 수 있고, 길게 누르면 복사돼요. |
| **문제** | JSHint가 찾은 문법 문제 목록이에요. |

파일이나 폴더를 길게 누르면 **이름 바꾸기**, **삭제**, (폴더에서) **파일 생성** 메뉴가 나와요. `project.json`, `config.json`, 메인 스크립트는 이름을 바꾸거나 지울 수 없어요.

## 편집 기능

- **자동 완성** — StarLight API 객체와 그 멤버, 코드 조각, 문서에 이미 쓴 단어를 제안해요.
- 괄호 자동 닫기, 코드 접기, 줄 옆의 문제 표시를 지원해요.
- 저장하지 않은 탭을 닫거나 에디터를 나가면 저장할지 물어봐요.

### 단축키 막대

화면 아래의 막대로 휴대폰 키보드에서 입력하기 번거로운 기호를 넣어요.

`↺ ↻ ⇒ ← → [ ] { } ( ) < > ; = . ' " + - * / \ : & |`

- `↺`는 실행 취소, `↻`는 다시 실행, `⇒`는 들여쓰기예요.
- `↺`, `↻`, `←`, `→`는 길게 누르면 계속 반복돼요.

### 하드웨어 키보드

| 키 | 하는 일 |
|---|---|
| `Ctrl`+`S` | 모두 저장 |
| `Ctrl`+`E` | 컴파일 |
| `Ctrl`+`L` | 서랍의 로그 탭 열기/닫기 |
| `Tab`, `Shift`+`Tab` | 들여쓰기, 내어쓰기 |

## 에디터 설정

아래쪽 막대를 위로 끌어 올리면 설정이 나와요.

| 분류 | 항목 |
|---|---|
| **일반** | **핫 키 표시**, **ESC 키 입력 무시**, **테마** |
| **코드** | **글자 크기**(8–32, 기본 15), **자동 줄바꿈(워드 랩)** |
| **탭** | **닫기 버튼 항상 표시**, **파일 언어 아이콘 표시**, **열린 탭 기억하기** |

> [!TIP]
> 긴 코드는 PC에서 쓰는 편이 편해요. `StarLight/projects/<이름>/` 폴더의 파일을 PC 에디터로 고친 뒤 기기에 복사하고, 앱에서 컴파일만 하면 돼요.
