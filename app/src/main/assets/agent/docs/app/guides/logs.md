## 로그 탭

**로그** 탭에는 앱 전체의 최근 로그가 시간순으로 쌓여요. 프로젝트의 컴파일 결과, 스크립트가 남긴 로그, 오류가 모두 여기에 나와요. 로그를 길게 누르면 복사돼요.

| 버튼 | 하는 일 |
|---|---|
| **표시 방식** | **카드** 또는 **텍스트**로 보여요. |
| **로그 필터** | 종류(INFO, WARN, ERROR, CRITICAL, DEBUG), 태그(쉼표로 구분), 메시지(정규식)로 걸러요. **필터 초기화**로 되돌려요. |
| **자동 스크롤** | 새 로그가 오면 맨 아래로 내려가요. |

## 프로젝트 로그

프로젝트 하나의 로그만 보려면 에디터의 서랍(☰)에서 **로그** 탭을 열어요. **로그 지우기**로 그 프로젝트의 로그를 비울 수 있어요. 프로젝트 로그는 `StarLight/projects/<이름>/logs.json`에 최근 것만 남아요.

## 스크립트에서 로그 남기기

NeonJS 프로젝트는 `console`, 두 언어 모두 `Log` API로 로그를 남겨요.

```javascript
console.log("메시지 받음:", event.message);   // NeonJS
Log.i("메시지 받음: " + event.message);         // NeonJS, Rhino
Log.e("API", "응답이 비었어요");                 // 태그와 함께
```

`Log`는 `v`/`d`/`i`/`w`/`e`(또는 `verbose`/`debug`/`info`/`warn`/`error`) 메서드로 단계를 정해요. [스크립트 API](/docs/app/reference/script-api#로그-log)를 보세요.

## 로그 파일

앱이 실행될 때마다 로그가 `StarLight/logs/<날짜>/<시각>.log` 파일로 저장돼요. **설정 → 로그**에서 관리해요.

| 설정 | 기본값 | 설명 |
|---|---|---|
| **로그 파일 보관 기간** | 30일 | 3일, 7일, 30일, 제한 없음 중에서 골라요. 지난 파일은 앱이 시작될 때 지워져요. |
| **로그 탭 표시 개수** | 100개 | 로그 탭에 보여 줄 개수예요. 100, 300, 500, 1000개 중에서 골라요. |
| **로그 파일 정리** | — | 지금 쓰는 파일만 남기고 로그 파일을 모두 지워요. |

> [!TIP]
> 받은 메시지를 모두 로그에 남기려면 **설정 → 알림, 이벤트**에서 **수신 메세지 로그 표시**를 켜세요. 봇이 메시지를 받고 있는지 확인할 때 유용해요.
