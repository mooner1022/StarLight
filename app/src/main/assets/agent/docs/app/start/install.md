## 1. 내려받기

StarLight는 **Google Play 판**과 **GitHub 판(APK)** 으로 배포돼요. 봇을 만들고 돌리는 데는 Google Play 판이면 충분하고, 플러그인이 필요하면 GitHub 판을 설치하세요.

- **Google Play 판** — [Google Play](https://play.google.com/store/apps/details?id=dev.mooner.starlight)에서 설치해요.
- **GitHub 판** — [다운로드](/#download)에서 채널을 골라 APK를 내려받아요.

### Google Play 판과 GitHub 판

| | Google Play 판 | GitHub 판 (APK) |
|---|---|---|
| 업데이트 | Google Play에서 받아요. | 앱의 **설정 → 업데이트 확인**에서 받아요. |
| 플러그인 | 쓸 수 없어요. | 스토어나 `.slp` 파일로 설치해요. |
| 데이터 위치 | 앱 전용 폴더예요. 앱을 지우면 함께 지워져요. | 내장 저장소의 `StarLight` 폴더예요. |
| 필수 권한 | 알림 접근, 다른 앱 위에 표시 | 파일 접근, 알림 접근, 다른 앱 위에 표시 |
| 스크립트의 Java 접근 | 리플렉션, 클래스 로딩, 프로세스 실행 등 일부를 쓸 수 없어요. [자세히](/docs/neonjs/guides/java#google-play-판의-제한) | 제한이 없어요. |

> [!WARNING]
> 두 판은 같은 앱이라 한 기기에 하나만 설치돼요. 다른 판으로 바꾸려면 먼저 프로젝트를 [zip 파일로 내보내](/docs/app/guides/projects#내보내기와-가져오기) 백업하세요.

### APK 채널

| 채널 | 설명 |
|---|---|
| **정식** | 정식으로 배포된 빌드예요. |
| 베타 | 정식 배포 전에 미리 받아 보는 빌드예요. |
| 스냅샷 | 개발 중인 최신 빌드예요. 아직 배포되지 않은 변경이 들어 있어요. |

채널마다 버전이 달라서 화면과 기능이 이 문서와 다를 수 있어요. 지금 각 채널의 버전은 [다운로드](/#download)에서 볼 수 있어요.

내려받은 APK를 열어 설치해요. 처음이라면 **출처를 알 수 없는 앱 설치**를 허용해야 할 수 있어요.

> [!NOTE]
> 메시지를 읽으려면 기기에 **카카오톡**이 설치되어 있어야 해요. 다른 메신저는 플러그인으로 연동해요.

## 2. 처음 실행하기

앱을 처음 열면 다섯 쪽짜리 안내가 나와요.

1. **시작하기** — 첫 화면에서 **시작하기**를 눌러요.
2. **StarLight로 할 수 있는 일** — 앱의 기능을 소개해요. **다음**을 눌러요.
3. **권한을 허용해 주세요** — 필수 권한을 허용해요(GitHub 판은 세 가지, Google Play 판은 두 가지). 항목의 **허용**을 누르면 시스템 설정으로 이동하고, 허용하고 돌아오면 체크 표시로 바뀌어요. 모두 허용해야 다음으로 넘어가요.
4. **있으면 더 좋아요** — 권장 설정 두 가지예요. 나중에 설정에서도 바꿀 수 있어요.
5. **준비가 끝났어요** — **StarLight 시작하기**를 누르면 앱이 다시 시작되며 홈 화면이 열려요.

### 필수 권한

| 권한 | 하는 일 |
|---|---|
| **파일 접근** | 프로젝트와 플러그인을 기기의 `StarLight` 폴더에 저장해요. Android 11 이상에서는 **모든 파일 액세스** 화면이 열려요. GitHub 판에서만 요청해요. |
| **알림 접근** | 메신저 알림을 읽어 봇이 메시지를 받고 답장할 수 있게 해요. 목록에서 StarLight를 켜 주세요. |
| **다른 앱 위에 표시** | 백그라운드에서 실행 중에도 화면을 띄울 수 있게 해요. |

### 권장 설정

| 설정 | 하는 일 |
|---|---|
| **알림 표시** | 실행 상태와 오류를 알림으로 알려 줘요. Android 13 이상에서만 보여요. |
| **배터리 최적화 제외** | 시스템이 백그라운드에서 StarLight를 종료하지 않게 해요. 봇을 오래 켜 두려면 꼭 허용하세요. |

> [!TIP]
> 제조사에 따라 배터리 최적화 말고도 앱을 잠재우는 기능이 있어요. 삼성 기기라면 배터리 설정의 **백그라운드 사용 한도**에서 StarLight를 **절전 예외 앱**에 넣어 두세요.

## 3. 실행 중 알림

StarLight는 실행되는 동안 **StarLight 실행중** 알림을 계속 띄워 둬요. 시스템이 앱을 종료하지 않도록 하는 알림이라 끄지 않는 것이 좋아요. 알림을 누르면 앱이 열려요.

## StarLight 폴더

GitHub 판은 내장 저장소에 `StarLight` 폴더(`/storage/emulated/0/StarLight`)를 만들어 프로젝트, 플러그인, 로그, 설정을 저장해요. 파일 관리자나 PC에서 이 폴더를 열어 스크립트를 복사하거나 백업할 수 있어요. 자세한 구조는 [폴더 구조](/docs/app/reference/folders)를 보세요.

Google Play 판은 같은 구조를 앱 전용 폴더(`/storage/emulated/0/Android/data/dev.mooner.starlight/files`)에 저장해요. 기기의 파일 관리자에서는 보이지 않을 수 있고, 앱을 지우면 함께 지워져요. 프로젝트를 백업하거나 옮길 때는 [zip 파일로 내보내기](/docs/app/guides/projects#내보내기와-가져오기)를 쓰세요.
