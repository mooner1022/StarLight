## 1.0.0 - 2026-11-03
### 주요 변경 사항
+ **StarLight AI** 추가
  + 대화로 프로젝트를 만들고, 코드를 고치고, 컴파일하고, 디버그 룸에서 시험까지 하는 AI 에이전트
  + Anthropic, ChatGPT 계정 로그인, OpenAI, Google Gemini, OpenRouter, OpenAI 호환 서버(Ollama 등) 지원
  + 앱을 닫아도 작업을 이어 가며, 진행 상황을 알림으로 표시 (지원하는 기기에서는 실시간 정보로 표시)
  + 프로젝트 삭제, 켜고 끄기 같은 작업은 실행 전에 승인 요청 (알림에서도 승인 가능)
  + 사진·파일 첨부, 에이전트가 보낸 파일과 프로젝트 바로가기 카드, 마크다운·텍스트·이미지 미리보기
  + 작업 계획 보드, 에이전트가 바꾼 내용 되돌리기와 변경 내용 보기, 선택지로 묻는 질문, 계획 모드
  + 프로젝트 메모(`AGENTS.md`), 긴 대화 자동 요약, 웹 페이지 읽기
  + 대화 제목 자동 생성과 이름 바꾸기
  + 대화 기록을 StarLight 폴더에 보관해 앱을 다시 설치해도 유지되며, zip 파일로 내보내기·가져오기 가능
  + 하단 AI 탭, 프로젝트 목록의 AI 버튼, 홈 위젯에서 시작
+ **NeonJS** 언어 추가
  + ES 모듈(`import`/`export`), `async`/`await`, `fetch`, `WebSocket` 지원
  + 실행 모드(인터프리터/컴파일/적응형)와 실험적 고급 최적화 옵션
  + 처리되지 않은 오류와 Promise 거부를 프로젝트 로그에 표시
+ **플러그인 스토어** 추가
  + 스토어에서 플러그인 검색·설치·업데이트, 필요한 의존 플러그인 함께 설치
  + 카테고리별 분류, 플러그인 정보에 설치 출처 표시
+ **미디어 전송** 기본 탑재 `(Hehee)`
  + 플러그인 없이 스크립트에서 채팅방으로 사진·동영상·파일 전송 (`MediaSharer.send`, `msg.room.sendMedia`)
  + 미디어 전송 설정 추가, 디버그 룸에서 봇이 보낸 파일 미리보기
+ **홈 화면** 개편
  + 위젯을 길게 눌러 위치와 크기를 바꾸는 편집형 그리드
  + 봇 상태, 오류 모니터, 실행 중인 작업, 메시지 활동, 스크립트 값 위젯 추가
  + 위젯별 설정 추가
+ **코드 에디터** 개편
  + CodeMirror 6으로 교체해 터치로 선택·복사·붙여넣기 지원
  + 찾기·바꾸기, 줄 이동, 문법 검사, API 자동 완성, 이벤트 함수 스니펫
  + 탭과 사이드 메뉴 재디자인
+ **프로젝트** 개선
  + 프로젝트 목록 재디자인, 검색 추가
  + 새 프로젝트 만들기를 단계별(이름, 언어, 이벤트, 언어 설정)로 개편
  + 프로젝트를 zip 파일로 내보내기·가져오기
+ **플러그인 탭** 개편
  + 파일에서 플러그인 설치, 플러그인별 켜기·끄기, 불러오지 못한 이유 표시
  + 초기 설정이 필요한 플러그인은 설정 창에서 바로 입력
+ **디자인** 개선
  + 처음 실행 안내 화면 재구성
  + 앱의 팝업을 아래에서 올라오는 시트로 통일
  + 다크 모드에서 밤하늘 헤더 표시
+ **설정** 정리
  + 쉬운 모드 제거, 설정 항목 재배치
  + 알림 접근, 배터리 최적화 예외 등 권한 상태 표시
  + 로그 보관 기간과 로그 탭 표시 개수 설정 추가
+ 앱을 시작할 때 업데이트 자동 확인

### 버그 수정 / 개선 사항
+ 코드 에디터에서 탭을 바꾼 뒤 저장하면 수정 내용이 사라지던 문제 수정
+ 프로젝트를 끄거나 삭제한 뒤에도 `setTimeout`/`setInterval` 타이머가 남던 문제 수정
+ 프로젝트를 만들 때 고른 플러그인 이벤트가 재시작 후 사라지던 문제 수정
+ 프로젝트 정렬의 "활성화 우선"이 적용되지 않던 문제와, 내림차순 정렬 시 즐겨찾기가 아래로 가던 문제 수정
+ 플러그인 하나를 불러오지 못하면 앱 시작이 중단되던 문제 수정
+ 플러그인 의존성을 올바른 순서로 불러오고, 의존성이 맞지 않는 플러그인은 건너뛰도록 수정
+ 설정 파일을 안전하게 저장하고, 손상된 설정 파일에서 복구하도록 개선
+ 동작 버튼이 없는 알림도 `onNotificationPosted`로 전달되도록 수정
+ 프로젝트 이벤트를 공용 작업자에서 처리해 여러 프로젝트를 켰을 때의 자원 사용 개선, 대기 중인 이벤트를 작업 위젯에 표시
+ 로그 파일이 지워지지 않고 계속 쌓이던 문제 수정
+ 로그 탭과 로그 위젯이 비어 있을 때 앱이 종료되던 문제 수정
+ 업데이트 설치 권한 요청이 잘못된 화면을 열던 문제 수정
+ 상태 표시줄의 알림 아이콘을 단색 아이콘으로 변경
+ 설정 화면 항목 디자인 통일, 반응 속도 개선

### 호환성 / 주의 사항
+ Android 8.0 이상이 필요합니다. (Android 7.x 지원 종료)
+ '다른 앱 위에 표시' 권한이 필수 권한에 추가되었습니다.
+ Google Play 배포판에서는 플러그인, 플러그인 스토어, 앱 내 업데이트를 사용할 수 없습니다.

### 개발자 변경 사항
+ PluginCore 1.0.0: 앱과 같은 버전을 쓰며, 지원하는 API 범위 안의 플러그인을 불러옵니다.
+ 플러그인 초기 설정 API 추가 (`isSetupRequired`, `getSetupStructure`, `onSetup`, `requestSetup`)
+ `starlight.json`에 `category` 항목 추가
+ 위젯 DSL과 그리드 크기, 위젯별 설정 API 추가
+ 스크립트에서 홈의 스크립트 값 위젯에 값을 표시하는 `HomeWidget` API 추가
+ `ChatRoom.sendMedia` 추가
+ ConfigDSL에 `info`, `progress`, `textList`, `choice`, `multiChoice` 옵션, 버튼 스타일과 확인 창, 실시간 값 표시, 값에 따른 항목 숨기기 추가
